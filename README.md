# Global Disaster Resilience Analytics

An end-to-end data analytics and visualization project focused on evaluating global disaster resilience using multi-source datasets, data integration, feature engineering, and interactive Tableau dashboards.

---

# Project Overview

This project analyzes global disaster resilience patterns by integrating datasets related to:

- GDP and economic indicators
- Human development metrics
- Governance indicators
- Water resource accessibility
- Population statistics
- Disaster impact datasets

The project combines multiple international datasets to build a unified analytical framework for evaluating disaster resilience and recovery trends across countries.

---

# Objectives

- Integrate multiple global datasets into a unified analytical dataset
- Perform data preprocessing and cleaning
- Engineer resilience-related indicators
- Analyze disaster vulnerability and recovery patterns
- Build interactive visual dashboards using Tableau
- Generate meaningful insights from multi-dimensional data

---

# Data Processing Workflow

The project workflow follows these stages:

1. Collection of raw datasets from multiple international sources
2. Dataset integration and merging
3. Data preprocessing and cleaning
4. Feature engineering and resilience metric creation
5. Final dataset preparation
6. Visualization and dashboard development using Tableau

# How to Generate the Final Dataset for Dashboard and Visualizations

The final dataset used for Tableau dashboards and visualizations is generated dynamically through the notebooks included in this repository.

Since the processed datasets are created programmatically during execution, they are not uploaded separately to the repository.

To generate the final dataset, follow these steps in sequence:

1. Run the **Data Integration Notebook** to merge all source datasets.
2. Run the **Data Cleaning Notebook** to preprocess and clean the integrated dataset.
3. Run the **Final Analysis Notebook** to generate the final dataset used for dashboards and visualizations.

After executing the notebooks in order, the final processed dataset required for Tableau visualizations will be automatically generated.
